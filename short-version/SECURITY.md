# Security

To report a vulnerability in answer-frames or short-version, please use GitHub's private reporting: open https://github.com/LorenzoColombani/claude-mods/security/advisories/new (the repository's **Security** tab, then **Report a vulnerability**). Only the maintainer sees the report.

Please don't open a public issue for a security problem. Reports are acknowledged within a week, and a fix is released as a new version on the `main` branch.

Supported versions: the latest version on `main`.
