# Privacy: answer-frames

answer-frames handles no personal data.

It only changes how messages are drawn in your Claude Code terminal. It does not collect, store or send anything: it runs no commands, reads no files, and makes no network or model calls. The text it draws is the text Claude Code already shows you, and it never leaves your machine because of this mod.

Questions: open an issue at https://github.com/LorenzoColombani/claude-mods/issues
